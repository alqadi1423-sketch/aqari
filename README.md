# عقاري · تابع لمنصة رِكز

تطبيق أندرويد وiOS لإدارة العقارات والإيجارات، منقول من النموذج المرجعي `aqari.html`
(المواصفة الوظيفية الملزمة) بإعادة بناء طبقتي **التخزين** و**العرض**، ثم أُضيف إليه الحساب والمزامنة والمنشأة.
وثيقة التصميم الكاملة: [docs/DESIGN.md](docs/DESIGN.md)، وصلاحيات الأقسام: [docs/PERMISSIONS.md](docs/PERMISSIONS.md).

- **القاعدة المحلية مصدر الحقيقة** والسحابة طبقة مضافة: SQLite (WAL · foreign_keys · synchronous=FULL)، جدول لكل كيان، والمبالغ أعداد صحيحة بالهللات. بعد الدخول الأول يعمل التطبيق بلا اتصال.
- **الدخول بحساب قوقل** (Firebase Auth عبر REST) والرموز في المخزن الآمن. بيانات كل حساب نسخة مستقلة على الجهاز: الخروج يركنها مقفلةً ولا يمسحها.
- **مزامنة بين الأجهزة** عبر Firestore REST بلا حزمة Firebase: طابور صادر ووارد، والأحدث تغييراً بساعة الخادم يغلب على مستوى الصف، والقيد المرحّل إضافة فقط.
- **المنشأة والأعضاء**: المالك يدعو أعضاء بالبريد، ولكل عضو مستوى في كل قسم (لا · عرض · إدخال · كامل) وعقارات محددة، تفرضها الواجهة على الجهاز و`firestore.rules` على الخادم.
- الأرصدة كلها **مشتقّة** من دفتر القيود: لا عمود رصيد في أي جدول، والقيد غير المتوازن يُرفض بمحفّز داخل القاعدة، والتصحيح بقيد عكسي.
- الملفات معنونة بالمحتوى (`attachments/<sha256>.<ext>`): رفع نفس الملف مرتين = ملف واحد.
- **النسخ الاحتياطي** أرشيف مُتحقَّق منه (بيان + بصمات + `integrity_check` + مطابقة أعداد) بكلمة مرور اختيارية، على الجهاز أو في مجلد التطبيق المخفي على Google Drive. والاستعادة بتشغيل تجريبي ونسخة أمان وتبديل ذرّي.

## التشغيل

```bash
npm install
npx expo run:android    # بناء تطوير كامل لأندرويد
npx expo run:ios        # بناء تطوير كامل لـ iOS
npm run typecheck       # فحص الأنواع
```

الربط بقوقل يُقرأ وقت البناء من `EXPO_PUBLIC_FIREBASE_API_KEY` و`EXPO_PUBLIC_FIREBASE_PROJECT_ID` و`EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID`. غيابها يعني بناءً بلا ربط: التطبيق يعمل محلياً كاملاً بلا دخول ولا مزامنة.

## الاختبارات

```bash
npm test
```

تعمل على Node مباشرة عبر `node:sqlite` المدمج (يلزم Node ≥ 22.5) على منطق العمل نفسه بلا بيئة React Native.
وتغطي النسخ الاحتياطي والاستعادة والتشفير، والمحاسبة وفحوص المطابقة، وقواعد العمل، والمزامنة، والصلاحيات وتوليد القواعد، والأداء تحت الحمل، وقراءة PDF، وحراسة النصوص (لا شرطة ولا `Text` خام).

اختبارات قواعد الأمان والمنشأة (`tests/*.emulator.test.ts`) تُتخطّى ما لم يكن محاكي Firestore قائماً، وتُشغَّل به:

```bash
firebase emulators:exec --only firestore --project demo-aqari "npx jest tests/firestoreRules.emulator.test.ts"
```

## البنية

```
app/             شاشات Expo Router: تنقّل سفلي بخمسة تبويبات + شاشات «المزيد» والإعدادات
src/db/          المخطط والهجرات وجداول المزامنة ومحوّلا SQLite (expo-sqlite للتطبيق، node:sqlite للاختبارات)
src/domain/      منطق العمل الخالص: المحاسبة، العقود، الأقساط، قراءة PDF، النسخ الاحتياطي، الصلاحيات…
src/repos/       طبقة الوصول للبيانات
src/files/       مخزن الملفات المعنون بالمحتوى
src/cloud/       عملاء REST: الدخول، Firestore، Google Drive
src/sync/        محرّك المزامنة ورؤية الصفوف في المنشأة
src/services/    ربط المنطق بالجهاز: الحساب والمزامنة، المنشأة، النسخ، الطباعة، التنبيهات
src/perf/        قياس الأداء داخل التطبيق
src/ui/          مكوّنات التصميم الأصلية (بطاقات، نوافذ سفلية، حقول، الخريطة…)
scripts/         gen-leaflet.js يولّد حزمة الخريطة المضمّنة
tests/           حزمة اختبارات Jest
firestore.rules  قواعد أمان السحابة (قسم المنشأة مولَّد من src/domain/access/rulesGen.ts)
```
