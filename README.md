# عقاري — تابع لمنصة رِكز

تطبيق أندرويد وiOS لإدارة العقارات والإيجارات، منقول حرفياً من النموذج المرجعي `aqari.html`
(المواصفة الوظيفية الملزمة)، بإعادة بناء طبقتي **التخزين** و**العرض** فقط.
وثيقة التصميم الكاملة: [docs/DESIGN.md](docs/DESIGN.md).

- **لا خادم · لا حساب مستخدم · لا إنترنت · جهاز واحد**
- قاعدة بيانات SQLite (WAL · foreign_keys · synchronous=FULL) — جدول لكل كيان، والمبالغ أعداد صحيحة بالهللات
- الأرصدة كلها **مشتقّة** من دفتر القيود — لا عمود رصيد في أي جدول، والقيد غير المتوازن يُرفض بمحفّز داخل القاعدة
- الملفات معنونة بالمحتوى (`attachments/<sha256>.<ext>`) — رفع نفس الملف مرتين = ملف واحد
- النسخ الاحتياطي أرشيف مُتحقَّق منه (بيان + بصمات + `integrity_check` + مطابقة أعداد)، والاستعادة بتشغيل تجريبي ونسخة أمان وتبديل ذرّي

## التشغيل

```bash
npm install
npx expo start          # للتطوير مع Expo Go (بعض الوحدات الأصلية تتطلب بناء تطوير)
npx expo run:android    # بناء تطوير كامل لأندرويد
npx expo run:ios        # بناء تطوير كامل لـ iOS
```

## الاختبارات — شرط التسليم

```bash
npm test
```

تعمل على Node مباشرة (عبر `node:sqlite` المدمج — يلزم Node ≥ 22.5) وتغطي:

- **النسخ الاحتياطي (١٢ اختباراً)**: ٥٠٠٠ مرفق واستعادة نظيفة، قطع النسخ والاستعادة، العبث بالأرشيف، الملف المفقود، الهجرة والرفض المؤدَّب، امتلاء المساحة، الإغلاق القسري، ثبات البصمة عبر ١٠٠ دورة، منع التكرار، تعطيل التجزئة
- **المحاسبة**: توازن المدين والدائن، إعادة الاحتساب من الصفر، الأحداث الأحد عشر، الفحوص الستة، محفّز الرفض
- **قواعد العمل**: اختبار لكل قاعدة من الثلاث عشرة
- **قراءة PDF**: الترتيبان المنطقي والبصري ١٠/١٠، وأسماء «قاسم» و«الاسمري» لا تُقصّ

## البنية

```
app/            شاشات Expo Router — تنقّل سفلي بخمسة تبويبات + شاشات «المزيد» والإعدادات
src/db/         المخطط والهجرات ومحوّلا SQLite (expo-sqlite للتطبيق، node:sqlite للاختبارات)
src/domain/     منطق العمل الخالص: المحاسبة، العقود، الأقساط، قراءة PDF، النسخ الاحتياطي…
src/files/      مخزن الملفات المعنون بالمحتوى
src/services/   الطباعة، التنبيهات، النسخ الاحتياطي، قراءة العقود
src/ui/         مكوّنات التصميم الأصلية (بطاقات، نوافذ سفلية، حقول…)
tests/          حزمة اختبارات شرط التسليم
```
